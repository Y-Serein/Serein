# Changelog

## 0.0.4 - 2026-06-02

- Confirm the tracked product, release, and example files use the Serein project identity.
- Stop tracking local context and handoff artifacts so release commits only carry source, product, and deliverable files.
- Align desktop release metadata and expected Windows installer paths for the Serein 0.0.4 release.

## 0.0.2 - 2026-06-01

- Harden Rich Edit file handling around CRLF line endings while preserving the original file line ending on save.
- Improve Vault sidebar selection, new-note placement, and lazy directory refresh behavior.
- Add safer unsaved-change navigation with Save and Continue / Continue without Saving / Cancel choices.
- Refine code block spacing, language controls, context menus, image handling, settings, and release workflow checks.

## 0.0.1 - 2026-05-29

- Rename desktop product identity to Serein.
- Add bilingual Chinese/English UI switching.
- Replace browser-native prompt, confirm, and alert dialogs with in-app dialogs.
- Add configurable editor fonts and font size presets.
- Add Vault index, backlinks, and local graph panels.
- Keep Vault directory browsing lazy-loaded to avoid large directory freezes.
