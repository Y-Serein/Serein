1. 快速开始

Serein 是本地 Markdown 桌面写作工具。文件保存在你的电脑上，Serein 不提供云同步，也不会上传你的文档。

  1. 启动 Serein。
  2. 点击左侧栏的“打开”，或使用 `文件 -> 打开 Vault`。
  3. 选择一个本地文件夹作为 Vault。
  4. 点击 `.md`、`.markdown` 或 `.txt` 文件开始编辑。

推荐用法

  • 日常写作：使用 Rich Edit。
  • 精确改 Markdown：使用 Plain Edit。
  • 做知识库：用文件夹组织路径，用标签分类，用链接建立关系。

单文件使用

如果只是临时打开一个文件，可以使用 `文件 -> 打开文件`。如果要使用反链、图谱、标签和快速打开，建议打开整个文件夹为 Vault。

3. Vault 与文件管理

Vault 就是一个本地文件夹。Serein 会读取其中的 Markdown / 文本文件，并基于这些文件建立索引。

打开与新建

文件
  • `文件 -> 打开 Vault`：打开一个本地文件夹。
  • `文件 -> 打开文件`：打开单个文件。
  • `文件 -> 新建笔记` 或 `Ctrl+N`：新建文档。
  • `文件 -> 新建文件夹`：在当前选中目录中新建文件夹。

保存与另存为

数据安全
  • `Ctrl+S` 保存当前文件。
  • `Ctrl+Shift+S` 另存为。
  • 切换文件前，如果有未保存修改，Serein 会提示保存或放弃。

重命名

链接更新

在文件树中右键文件或点击行右侧按钮。若其他文件链接到旧文件，Serein 会询问是否同步更新链接。

删除

非永久删除

删除会移动到 Serein 应用数据回收站，不会直接永久删除磁盘文件。删除前仍要确认目标是否正确。

支持索引的文件类型：`.md`、`.markdown`、`.txt`。其他文件可以放在 Vault 中，但不会作为知识库文档进入反链和图谱。

4. 编辑模式

Serein 有 Rich Edit 和 Plain Edit。两种模式编辑的是同一份 Markdown。

Rich Edit

所见即所得模式，适合日常写作。支持标题、列表、引用、链接、图片、代码块、表格等常见 Markdown 结构。

Plain Edit

源码模式，适合精确编辑 frontmatter、路径、复杂链接和 Markdown 语法。

模式记忆

切换 Rich Edit 或 Plain Edit 会作为全局偏好保存。之后打开其他文件也沿用上次模式；没有记录或记录异常时默认使用 Rich Edit。

桌面操作边界

搜索框、命令面板、属性输入框等输入区域会优先响应自己的复制、粘贴、撤销和全选，不会把整个界面一起选中。

切换方式：右上角模式按钮、`视图 -> Rich Edit / Plain Edit`、`Ctrl+Alt+R`、`Ctrl+Alt+P`。

6. Obsidian / Vault 语法

这是 Serein 知识库能力的核心：路径、标签、属性、链接和别名。

路径

路径来自 Vault 文件树里的文件夹和文件相对位置，不需要额外创建语法。

Projects/
  Atlas.md
Notes/
  Research.md

可以写：`[[Projects/Atlas]]` 或 `[研究](./Notes/Research.md)`。

标签

#project
#project/atlas

正文里写 `#project` 是标签。左侧搜索里用 `@project` 搜标签，`#Project` 用于搜索标题。

属性区 / YAML frontmatter

---
tags: [project, writing]
aliases: [Atlas, Project Atlas]
status: active
---

这是文件开头的属性区，不是正文。`tags` 是标签，`aliases` 是别名，`status` 可用来表示 active / inactive。

project writing --- tags --- Atlas, Project Atlas

在 Rich Edit 中，属性区会收起成一行 `--- tags ---`。鼠标移到这一行或用键盘跳到这一行时，左侧显示标签，右侧显示别名，可以直接编辑。

Wiki 链接

[[note]]
[[note#heading]]
[[note|alias]]
[[path/note#heading|alias]]

建议公开使用时写带路径的链接，避免同名文件歧义。

属性行补充：标签和别名输入支持空格、英文逗号或中文逗号分隔；包含空格的别名建议用逗号分隔，例如 `Atlas, Project Atlas`。点击中间 `--- tags ---` 可切换 active / inactive。标签和别名都清空后，可用 Delete / Backspace 删除整行属性。
目录链接如 `[目录入口](./Notes/)` 会尝试解析到 `index.md`、`index.markdown`、`index.txt`、`README.md`、`README.markdown` 或 `README.txt`。

            8. 图片

            可以通过菜单、粘贴或拖拽插入图片。插入图片前，当前文档需要先保存到磁盘。

            附件目录

            默认是 `./image_ys`，表示复制到当前文档旁边的 `image_ys` 子目录。

            相对路径

            更适合迁移 Vault，推荐日常使用。

            绝对路径

            依赖当前电脑路径，不建议用于可迁移笔记。

            9. 搜索与快速打开

            快速打开用于切换文件，搜索用于查标题、路径、标签和正文。

            快速打开

            `Ctrl+P` 或 `文件 -> 快速打开`。在当前 Vault 内按标题或路径快速切换文件。

            搜索

            `Ctrl+F` 或 `编辑 -> 搜索`。左侧搜索支持范围前缀；如果正文里已经选中文字，会自动填入搜索框。

            历史搜索

            搜索框为空时会显示历史搜索。可以点历史项重新搜索，也可以进入删除模式删除单项或一键清空。

            输入边界

            搜索框内的 `Ctrl+A` 只选择搜索框内容；复制、粘贴、撤销也优先作用于当前输入框。

            输入范围示例

            @关键词标签@work
            /关键词路径/docs
            #关键词标题#Project

            10. 知识面板

            右侧知识面板帮助你理解当前文档与 Vault 其他文档的关系。

            反链

            哪些文件链接到了当前文件。

            出链

            当前文件链接到了哪些文件，包含已解析、未解析和多候选链接。

            属性

            显示 YAML frontmatter，例如 tags、aliases、status。

            图谱

            查看当前文件附近或整个 Vault 的链接关系。

            标签

            列出当前 Vault 中识别到的标签。

            浮动/停靠

            知识面板可以从右侧栏脱离，也可以重新停靠。

            11. 图谱

            图谱依赖真实链接。没有链接时，图谱通常只有当前文件或为空。

            局部图谱

            围绕当前文件显示：当前文件、当前文件链接出去的文件、链接到当前文件的文件。

            全局图谱

            显示当前 Vault 的链接关系。可按标签筛选、只看孤立节点、显示未解析链接。

            如果图谱很少，说明文档之间还没有真实链接。先写 `[[Wiki Link]]` 或 `[text](./path.md)`。

            14. 数据安全和索引限制

            Serein 直接读写本地文件。它会尽量保护未保存修改，但你仍应确认文件路径和操作目标。

            安全保护

            • 切换文件前有未保存修改会提示。
            • 重命名前如果目标文件有未保存修改，会要求先保存。
            • 批量更新链接前，如果受影响文件有未保存修改，会要求先保存。
            • 当前文件被其他应用修改后，Serein 会在窗口聚焦、回到可见状态或定时检查时同步。
            • 删除移动到应用数据回收站，不直接永久删除。

            索引限制

            • 单层目录显示数量限制：300。
            • 最多索引文件数：2000。
            • 单个索引文件上限：1 MB。
            • 总索引内容上限：32 MB。
            外部修改同步：如果当前文档没有未保存内容，磁盘更新会自动读入当前编辑区；如果你正在 Serein 里改同一个文件，Serein 会提示冲突，不会直接覆盖你的未保存内容。
            不建议把 `node_modules`、`target`、`dist`、日志目录、大图片目录当作 Vault 内容。Serein 会跳过常见重型目录，但最好只打开真正写作目录。

            15. 常见问题

            公开用户最容易遇到的问题集中在属性、路径、图片和索引。

            frontmatter 是什么？

            文件开头 `---` 到 `---` 之间是属性区，不是正文。`tags` 是标签，`aliases` 是别名，`status` 是自定义状态。

            路径不知道怎么写

            看左侧文件树的相对位置。例如 `Projects/Atlas.md` 可以写 `[[Projects/Atlas]]`。

            图谱很少

            需要文件之间存在真实链接。先写 `[[Wiki Link]]` 或 Markdown 路径链接。

            链接未解析

            确认目标文件在当前 Vault 内，路径正确，目录链接下有 index 或 README。

            图片插入失败

            先保存当前文档，再插入图片。未保存文档没有附件目录。

            启动恢复失败

            进入 `设置 -> 文件`，点击 `清除上次 Vault 状态`，然后重新打开 Vault。

            为什么只看到 `--- tags ---`？

            这是 Rich Edit 把 YAML 属性区收起后的显示。鼠标移到这一行，或从正文第一行按 `↑` 跳上去，就能看到并编辑 tags 和 aliases。

            为什么搜索 `#project` 没结果？

            搜索前缀里 `@` 代表标签，`#` 代表标题。要搜标签请用 `@project`；正文里仍然写 `#project` 创建标签。

            外部工具改了文件怎么办？

            如果 Serein 当前文档没有未保存修改，会自动同步磁盘内容；如果有未保存修改，会提示冲突，需要你先比较再保存或另存为。
