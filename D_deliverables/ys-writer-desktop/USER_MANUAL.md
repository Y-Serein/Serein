# Serein 用户手册

## 1. 打开和管理文件

- 使用左侧文件页签打开本地 Vault。目录树是懒加载的，点击目录才会读取下一层。
- 单击文件名会在中间编辑区打开文件。
- 右键文件树里的文件，或右键中间顶部的文件标签，可以打开文件操作菜单。
- “打开所在文件夹”会调用系统文件管理器打开该文件所在目录。
- 重命名和删除只在 Vault 文件树中提供；删除会移到 Serein 应用数据回收站，不会直接永久删除磁盘文件。

## 2. 编辑和保存

- Rich Edit 更接近 Typora 的写作体验。
- Plain Edit 是纯 Markdown 文本编辑。
- 右上角可以切换 Rich Edit / Plain Edit。
- 切换文件、关闭标签或执行可能丢失修改的操作时，如果当前文件未保存，会出现保存确认。
- “保存并继续”会先保存当前文件，再继续刚才的操作。

## 3. 搜索

左侧“搜索”默认同时查标题、路径、标签和正文。

可以在搜索词前加前缀来指定范围：

| 输入 | 范围 | 示例 |
| --- | --- | --- |
| `关键词` | 全部 | `Serein` |
| `@关键词` | 标题 | `@Project` |
| `/关键词` | 路径 | `/docs` |
| `#关键词` | 标签 | `#work` |
| `:关键词` | 正文 | `:build_win` |

如果没有输入前缀，搜索行为和旧版本一致。

## 4. 标签

Serein 会从两类位置识别标签：

```markdown
#inline-tag
```

或 YAML frontmatter：

```markdown
---
tags: [project, writing]
---
```

识别到的标签会出现在左侧“标签”页签和右侧知识面板中。点击标签会切到搜索视图并按该标签筛选。

## 5. 书签

书签页签目前是预留入口，正式书签功能尚未启用。

当前替代方式：

- 用快速打开跳转文件。
- 用搜索定位标题、路径、标签或正文。
- 用标签页签进入同类笔记。
- 用右侧反链、出链和图谱查看文档关系。

## 6. 右侧知识面板

- 反链：哪些文件链接到了当前文件。
- 出链：当前文件链接到了哪些文件。
- 属性：当前文件的 YAML frontmatter 信息。
- 图谱：当前 Vault 或当前文件附近的链接关系。

如果知识面板为空，通常是因为当前文件还没有进入 Vault 索引，或文档之间没有写链接。

## 7. 常见问题

- 搜索不到内容：确认已经打开 Vault，并等待索引完成。
- 标签不显示：确认标签写成 `#tag` 或 YAML `tags`。
- 图谱很少：需要文件之间存在 `[[Wiki Link]]` 或 Markdown 链接。
- 打不开所在文件夹：确认文件是真实磁盘文件；demoVault 中的示例路径不会打开系统文件夹。
